# Синапс

## Назначение

Образовательное мини-приложение и бот в MAX для проверки знаний: 
учитель создаёт тесты (вручную или через ИИ), публикует их классу, 
получает аналитику; ученик проходит тесты, получает разбор ошибок 
и готовится через умные конспекты.

## Основной пользовательский сценарий

1. Учитель открывает мини-приложение из бота → создаёт класс
2. Добавляет учеников по MAX ID (ученик предварительно пишет регистрируется через чат бота)
3. Создаёт тест: вводит тему → ИИ генерирует вопросы → проверяет → публикует
4. Получает код теста → передаёт ученикам
5. Ученик вводит код → проходит тест пошагово → видит результат и разбор ошибок
6. Учитель открывает журнал класса → смотрит аналитику по тесту

Дополнительно: учитель может запланировать тест заранее с материалами 
для подготовки; ученик готовится через «Умный конспект» и тренировочный тест.

## Состав и архитектура

- **Backend** — FastAPI: API, авторизация через MAX initData, работа с БД, 
  интеграция с GigaChat
- **Frontend** — статический HTML/JS: мини-приложение MAX
- **Bot** — maxapi (long polling): команды, регистрация, уведомления
- **PostgreSQL** — хранение пользователей, классов, тестов, результатов
- **GigaChat** — генерация тестов и конспектов

Взаимодействие: MAX → бот + мини-приложение → FastAPI → PostgreSQL / GigaChat

## Известные ограничения

- Один класс на учителя (MVP)
- Уведомления доставляются только пользователям, написавшим боту
- ИИ может ошибаться — учитель проверяет вопросы перед публикацией
- Списки групп вводятся вручную (нет интеграции с журналами организаций)
